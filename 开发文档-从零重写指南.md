# 第 0 章 项目全貌

## 0.1 项目是什么

一个**私有化部署**的医疗 AI 问答平台：用户用自然语言问药品、疾病、养生问题，后端调用本地运行的 DeepSeek 大模型回答。大模型跑在本机 Ollama 上，医疗数据不出内网。

## 0.2 技术栈

| 层 | 技术 | 版本 |
|----|------|------|
| JDK | Java | 17 |
| 框架 | Spring Boot | 3.2.5 |
| AI | Spring AI + Ollama Starter | 1.0.0-M5 |
| 大模型 | DeepSeek-R1（经 Ollama 运行） | 1.5b |
| 安全 | Spring Security + JJWT | jjwt 0.12.5 |
| ORM | MyBatis（mybatis-spring-boot-starter） | 3.0.3 |
| 分页 | PageHelper | 2.1.0 |
| 数据库 | MySQL | 8.0 |
| 缓存/锁 | Redis + Redisson | Redisson 3.27.0 |
| 工具 | Hutool、Lombok | Hutool 5.8.26 |
| 前端 | Vue 3 + Vite + Element Plus + Pinia + Vue Router + Axios + marked | 见前端章节 |

## 0.3 分层架构

```
┌─────────────────────────────────────────────┐
│  前端 Vue3（5173 端口，/api 代理到 8080）       │
└──────────────────┬──────────────────────────┘
                   │ HTTP + JWT
┌──────────────────▼──────────────────────────┐
│  Controller 层（5 个，接收请求/参数校验/鉴权）   │

├─────────────────────────────────────────────┤
│  Service 层（业务逻辑）                        │
│  ├─ UserService          注册/登录/JWT         │
│  ├─ ChatService   ★核心  限流/缓存/锁/调AI     │
│  ├─ ChatHistoryService   历史分页/删除          │
│  ├─ KnowledgeService     知识搜索/详情          │
│  ├─ CollectService       收藏（批量查询优化）    │
│  └─ RemindService        学习提醒              │
├─────────────────────────────────────────────┤
│  基础设施：Spring Security 过滤器链 / Redis     │
│  PageHelper 分页 / 全局异常 / CORS             │
├─────────────────────────────────────────────┤
│  Mapper 接口 + XML（手写 SQL）                 │
├─────────────────────────────────────────────┤
│  MySQL（5 张表）   Redis（缓存/锁/限流/上下文）  │
│  Ollama（11434，本地大模型）                    │

```

```

│   └── WebMvcConfig.java              CORS
```

## 1.1 安装 Ollama 并拉取模型

```bash
# 1. 安装 Ollama：https://ollama.com/download 下载 Windows 版安装
# 2. 拉取 DeepSeek-R1 1.5B 小模型（约 1.1GB，CPU 可跑）
ollama pull deepseek-r1:1.5b

# 3. 验证模型可用
ollama run deepseek-r1:1.5b "你好"
```

Ollama 安装后默认监听 `http://127.0.0.1:11434`。

## 1.2 Maven 配置国内镜像（必做，否则依赖下载失败）

编辑 Maven 安装目录 `conf/settings.xml`（或 `C:\Users\你的用户名\.m2\settings.xml`），在 `<mirrors>` 中加入：

```xml
<mirror>
    <id>alimaven</id>
    <name>aliyun maven</name>
    <url>https://maven.aliyun.com/repository/public</url>
    <mirrorOf>central</mirrorOf>
</mirror>
```

> 注意必须是 `https` 且路径是 `/repository/public`，旧的 `http://maven.aliyun.com/nexus/content/groups/public/` 已失效。

## 1.3 启动依赖服务

```bash
# 启动 MySQL（服务名通常是 MySQL80）
net start MySQL80

# 启动 Redis
redis-server

# 确认 Ollama 在运行（桌面版安装后开机自启）
```

# 第 3 章 阶段一：数据库

创建 `sql/init.sql`，内容如下，直接执行：

```sql
CREATE DATABASE IF NOT EXISTS healthai_db DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE healthai_db;

-- 用户表
CREATE TABLE `ai_user` (
    `user_id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '用户ID',
    `username` VARCHAR(50) NOT NULL COMMENT '用户名',
    `password` VARCHAR(128) NOT NULL COMMENT '密码(MD5加密)',
    `phone` VARCHAR(20) DEFAULT NULL COMMENT '手机号',
    `email` VARCHAR(100) DEFAULT NULL COMMENT '邮箱',
    `avatar` VARCHAR(255) DEFAULT NULL COMMENT '头像URL',
    `role` TINYINT NOT NULL DEFAULT 0 COMMENT '角色 0-普通用户 1-管理员',
    `status` TINYINT NOT NULL DEFAULT 1 COMMENT '状态 0-禁用 1-正常',
    `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `update_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`user_id`),
    UNIQUE KEY `uk_username` (`username`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';

-- AI 对话历史表
CREATE TABLE `ai_chat_history` (
    `chat_id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '对话ID',
    `user_id` BIGINT NOT NULL COMMENT '用户ID',
    `question` TEXT NOT NULL COMMENT '用户问题',
    `answer` TEXT NOT NULL COMMENT 'AI回答',
    `session_id` VARCHAR(64) NOT NULL COMMENT '会话标识',
    `model_name` VARCHAR(50) DEFAULT 'deepseek-r1' COMMENT '模型名称',
    `response_time` INT DEFAULT NULL COMMENT '响应时间(毫秒)',
    `is_cached` TINYINT NOT NULL DEFAULT 0 COMMENT '是否缓存命中 0-否 1-是',
    `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    PRIMARY KEY (`chat_id`),
    KEY `idx_user_id` (`user_id`),
    KEY `idx_session_id` (`session_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='AI对话历史表';

-- 医药知识库表
CREATE TABLE `medical_knowledge` (
    `knowledge_id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '知识ID',
    `title` VARCHAR(200) NOT NULL COMMENT '知识标题',
    `category` VARCHAR(50) NOT NULL COMMENT '分类 药品/疾病/症状/检查/广告法规',
    `content` TEXT NOT NULL COMMENT '知识内容',
    `keywords` VARCHAR(500) DEFAULT NULL COMMENT '关键词,逗号分隔',
    `source` VARCHAR(100) DEFAULT NULL COMMENT '来源',
    `view_count` INT NOT NULL DEFAULT 0 COMMENT '浏览次数',
    `status` TINYINT NOT NULL DEFAULT 1 COMMENT '状态 0-下架 1-上架',
    `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `update_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`knowledge_id`),
    KEY `idx_category` (`category`),
    KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='医药知识库表';

-- 用户收藏表
CREATE TABLE `user_collect` (
    `collect_id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '收藏ID',
    `user_id` BIGINT NOT NULL COMMENT '用户ID',
    `knowledge_id` BIGINT NOT NULL COMMENT '知识ID',
    `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '收藏时间',
    PRIMARY KEY (`collect_id`),
    UNIQUE KEY `uk_user_knowledge` (`user_id`, `knowledge_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户收藏表';

-- 学习提醒表
CREATE TABLE `study_remind` (
    `remind_id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '提醒ID',
    `user_id` BIGINT NOT NULL COMMENT '用户ID',
    `title` VARCHAR(100) NOT NULL COMMENT '提醒标题',
    `content` VARCHAR(500) DEFAULT NULL COMMENT '提醒内容',
    `remind_time` DATETIME NOT NULL COMMENT '提醒时间',
    `remind_type` TINYINT NOT NULL DEFAULT 0 COMMENT '提醒类型 0-学习 1-复习 2-考试',
    `status` TINYINT NOT NULL DEFAULT 0 COMMENT '状态 0-未提醒 1-已提醒 2-已取消',
    `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    PRIMARY KEY (`remind_id`),
    KEY `idx_user_id` (`user_id`),
    KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学习提醒表';
```

## 5.3 JWT 工具 JwtUtils

`common/JwtUtils.java`。用 jjwt 0.12.x 的 API（注意 0.12 版本 API 与旧版不同）：

```java
package com.healthai.common;

import io.jsonwebtoken.Claims;
import io.jsonwebtoken.Jwts;
import io.jsonwebtoken.security.Keys;
import jakarta.annotation.PostConstruct;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

import javax.crypto.SecretKey;
import java.nio.charset.StandardCharsets;
import java.util.Date;

@Slf4j
@Component
public class JwtUtils {

    @Value("${healthai.jwt.secret-key:healthai-default-secret-key-change-me}")
    private String secret;

    private static SecretKey KEY;
    private static final long TTL = 7L * 24 * 60 * 60 * 1000;  // 7 天

    @PostConstruct
    public void init() {
        KEY = Keys.hmacShaKeyFor(secret.getBytes(StandardCharsets.UTF_8));
    }

    // 生成 token，载荷放 userId、username
    public static String generateToken(Long userId, String username) {
        return Jwts.builder()
                .subject(username)
                .claim("userId", userId)
                .issuedAt(new Date())
                .expiration(new Date(System.currentTimeMillis() + TTL))
                .signWith(KEY)
                .compact();
    }

    public static Claims parse(String token) {
        try {
            return Jwts.parser().verifyWith(KEY).build()
                    .parseSignedClaims(token).getPayload();
        } catch (Exception e) {
            return null;
        }
    }

    public static Long getUserId(String token) {
        Claims c = parse(token);
        return c == null ? null : c.get("userId", Long.class);
    }

    public static String getUsername(String token) {
        Claims c = parse(token);
        return c == null ? null : c.getSubject();
    }

    public static boolean isExpired(String token) {
        Claims c = parse(token);
        return c == null || c.getExpiration().before(new Date());
    }
}
```

## 5.4 JWT 认证过滤器

`config/JwtAuthenticationFilter.java`，继承 `OncePerRequestFilter`，每个请求只执行一次：

```java
package com.healthai.config;

import com.healthai.common.JwtUtils;
import jakarta.servlet.FilterChain;
import jakarta.servlet.*;
import jakarta.servlet.http.*;
import lombok.RequiredArgsConstructor;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.security.authentication.UsernamePasswordAuthenticationToken;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.stereotype.Component;
import org.springframework.web.filter.OncePerRequestFilter;
import java.io.IOException;
import java.util.*;

@Component
@RequiredArgsConstructor
public class JwtAuthenticationFilter extends OncePerRequestFilter {

    private final StringRedisTemplate redis;
    private static final String BLACKLIST = "healthai:token:blacklist:";

    @Override
    protected void doFilterInternal(HttpServletRequest req, HttpServletResponse resp,
                                    FilterChain chain) throws ServletException, IOException {
        String token = req.getHeader("Authorization");   // 本项目约定：裸 token，无 Bearer 前缀
        if (token != null && !token.isBlank()) {
            // 1. 是否过期
            if (JwtUtils.isExpired(token)) {
                writeUnauthorized(resp, "Token 已过期"); return;
            }
            // 2. 是否在登出黑名单
            if (Boolean.TRUE.equals(redis.hasKey(BLACKLIST + token))) {
                writeUnauthorized(resp, "Token 已失效"); return;
            }
            // 3. 解析用户，放进 request 属性 + SecurityContext
            Long userId = JwtUtils.getUserId(token);
            if (userId == null) { writeUnauthorized(resp, "Token 无效"); return; }
            req.setAttribute("userId", userId);
            req.setAttribute("username", JwtUtils.getUsername(token));
            UsernamePasswordAuthenticationToken auth =
                    new UsernamePasswordAuthenticationToken(userId, null, new ArrayList<>());
            SecurityContextHolder.getContext().setAuthentication(auth);
        }
        chain.doFilter(req, resp);
    }

    private void writeUnauthorized(HttpServletResponse resp, String msg) throws IOException {
        resp.setStatus(401);
        resp.setContentType("application/json;charset=UTF-8");
        resp.getWriter().write("{\"code\":401,\"message\":\"" + msg + "\"}");
    }
}
```

`config/SecurityConfig.java`：

```java
package com.healthai.config;

import lombok.RequiredArgsConstructor;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.web.SecurityFilterChain;
import org.springframework.security.web.authentication.UsernamePasswordAuthenticationFilter;

@Configuration
@EnableWebSecurity
@RequiredArgsConstructor
public class SecurityConfig {

    private final JwtAuthenticationFilter jwtFilter;

    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http.csrf(csrf -> csrf.disable())
            .sessionManagement(s -> s.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/api/auth/**", "/api/knowledge/**").permitAll()  // 放行
                .requestMatchers("/api/chat/**", "/api/collect/**", "/api/remind/**").authenticated()
                .anyRequest().authenticated())
            .addFilterBefore(jwtFilter, UsernamePasswordAuthenticationFilter.class);
        return http.build();
    }
}
```

权限规划：

| 路径 | 权限 |
|------|------|
| `/api/auth/**`、`/api/knowledge/**` | 放行（登录注册、知识库无需登录） |
| `/api/chat/**`、`/api/collect/**`、`/api/remind/**` | 需登录 |

## 5.7 分页配置（PageHelper，无需 Java 配置类）

原生 MyBatis 方案下分页用 **PageHelper**，已经在 4.2 引入依赖、4.3 的 yml 中配好方言，**不需要再写任何配置类**。

使用方式固定为"**紧贴查询语句**"调用 `PageHelper.startPage(pageNum, pageSize)`，它会通过 MyBatis 拦截器自动在下一条查询 SQL 后面拼 `LIMIT`，并执行一次 `COUNT` 查询：

```java
PageHelper.startPage(pageNum, pageSize);                    // 对紧接的下一条查询生效
List<XxxEntity> list = xxxMapper.selectList(查询参数);        // 自动被分页
PageInfo<XxxEntity> pageInfo = new PageInfo<>(list);        // 取出分页信息
// pageInfo.getList() 当前页数据；pageInfo.getTotal() 总条数；getPageNum()/getPageSize()
```

> 注意：`startPage` 和查询语句之间不能插入其他查询，否则会分页到错误的 SQL 上。

```java
import com.healthai.common.Result;

import org.springframework.web.bind.annotation.*;

    }

    @ExceptionHandler(MethodArgumentNotValidException.class)

        FieldError fe = e.getBindingResult().getFieldError();
        String msg = fe != null ? fe.getDefaultMessage() : "参数校验失败";
        return Result.error(400, msg);
    }

    @ExceptionHandler(Exception.class)
    public Result<?> handleException(Exception e) {
        log.error("系统异常", e);
        return Result.error("系统繁忙,请稍后再试");
    }
}
```

```java
package com.healthai.common;

import jakarta.annotation.PostConstruct;
import jakarta.annotation.PreDestroy;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.redisson.api.RBloomFilter;
import org.redisson.api.RedissonClient;
import org.springframework.stereotype.Component;

@Slf4j
@Component
@RequiredArgsConstructor
public class BloomFilterUtils {

    private final RedissonClient redisson;
    private RBloomFilter<String> bloomFilter;

    private static final String KEY = "healthai:bloom:answer";
    private static final long CAPACITY = 1_000_000L;   // 100 万问题
    private static final double ERROR_RATE = 0.0001;  // 误判率 0.01%

    @PostConstruct
    public void init() {
        bloomFilter = redisson.getBloomFilter(KEY);
        bloomFilter.tryInit(CAPACITY, ERROR_RATE);   // 幂等，已初始化不会重置
    }

    public void add(String question) {
        bloomFilter.add(question.toLowerCase().trim());
    }

    public boolean mightContain(String question) {
        return bloomFilter.contains(question.toLowerCase().trim());
    }

    @PreDestroy
    public void destroy() { bloomFilter = null; }
}
```

## 5.12 AOP 操作日志（注解 + 切面）

**注解** `common/OperationLog.java`：

```java
package com.healthai.common;

import java.lang.annotation.*;

@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)   // 运行时可通过反射读取
public @interface OperationLog {
    String module() default "";       // 模块名
    String operation() default "";    // 操作描述
}
```

**切面** `aspect/LogAspect.java`（核心逻辑）：

```java
package com.healthai.aspect;

import com.healthai.common.OperationLog;
import jakarta.servlet.http.HttpServletRequest;
import lombok.extern.slf4j.Slf4j;
import org.aspectj.lang.ProceedingJoinPoint;
import org.aspectj.lang.annotation.Around;
import org.aspectj.lang.annotation.Aspect;
import org.aspectj.lang.reflect.MethodSignature;
import org.springframework.stereotype.Component;
import org.springframework.web.context.request.*;

@Slf4j
@Aspect
@Component
public class LogAspect {

    @Around("@annotation(com.healthai.common.OperationLog)")
    public Object around(ProceedingJoinPoint pjp) throws Throwable {
        // 1. 取注解上的 module/operation
        MethodSignature sig = (MethodSignature) pjp.getSignature();
        OperationLog anno = sig.getMethod().getAnnotation(OperationLog.class);

        // 2. 取 request，提取 URI、IP、userId
        ServletRequestAttributes attr = (ServletRequestAttributes)
                RequestContextHolder.getRequestAttributes();
        HttpServletRequest req = attr.getRequest();
        Object userId = req.getAttribute("userId");   // JWT 过滤器设置
        if (userId == null) userId = "anonymous";

        long start = System.currentTimeMillis();
        log.info("[{} - {}] {} {} 用户={} IP={}",
                anno.module(), anno.operation(),
                req.getMethod(), req.getRequestURI(), userId, getIp(req));

        try {
            Object result = pjp.proceed();   // 执行目标方法
            log.info("[{} - {}] 成功，耗时 {} ms",
                    anno.module(), anno.operation(),
                    System.currentTimeMillis() - start);
            return result;
        } catch (Throwable e) {
            log.error("[{} - {}] 异常：{}，耗时 {} ms",
                    anno.module(), anno.operation(), e.toString(),
                    System.currentTimeMillis() - start);
            throw e;   // 关键：记录后必须重新抛出，不能吞异常
        }
    }

    // 穿透代理拿真实 IP
    private String getIp(HttpServletRequest req) {
        String[] headers = {"X-Forwarded-For","X-Real-IP","Proxy-Client-IP"};
        for (String h : headers) {
            String ip = req.getHeader(h);
            if (ip != null && !ip.isBlank() && !"unknown".equalsIgnoreCase(ip)) {
                return ip.contains(",") ? ip.split(",")[0].trim() : ip;
            }
        }
        return req.getRemoteAddr();
    }
}
```

> 完整版还可加入参打印 + password/token 脱敏，思路：遍历 `sig.getParameterNames()`，参数名包含 password/token 的打印 `****`。

### Mapper XML：手写 SQL

路径固定为 `src/main/resources/mapper/UserMapper.xml`（与 yml 的 `mapper-locations` 对应）：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.healthai.mapper.UserMapper">

    <select id="findByUsername" resultType="com.healthai.entity.UserEntity">
        SELECT user_id, username, password, phone, email, avatar, role, status,
               create_time, update_time
        FROM ai_user
        WHERE username = #{username}
    </select>

    <select id="findById" resultType="com.healthai.entity.UserEntity">
        SELECT user_id, username, password, phone, email, avatar, role, status,
               create_time, update_time
        FROM ai_user
        WHERE user_id = #{userId}
    </select>

    <select id="countByUsername" resultType="int">
        SELECT COUNT(*) FROM ai_user WHERE username = #{username}
    </select>

    <!-- useGeneratedKeys：把自增主键回填到实体的 userId 属性 -->
    <insert id="insert" parameterType="com.healthai.entity.UserEntity"
            useGeneratedKeys="true" keyProperty="userId">
        INSERT INTO ai_user (username, password, phone, email, avatar, role, status)
        VALUES (#{username}, #{password}, #{phone}, #{email}, #{avatar}, #{role}, #{status})
    </insert>

    <!-- <set> 动态标签：属性为 null 的字段不会出现在 UPDATE 中 -->
    <update id="updateById" parameterType="com.healthai.entity.UserEntity">
        UPDATE ai_user
        <set>
            <if test="phone != null">phone = #{phone},</if>
            <if test="email != null">email = #{email},</if>
            <if test="avatar != null">avatar = #{avatar},</if>
        </set>
        WHERE user_id = #{userId}
    </update>

</mapper>
```

**原生 MyBatis 的三个要点**：
1. XML 的 `namespace` 必须等于 Mapper 接口全限定名，`id` 必须等于方法名；
2. 开启驼峰映射后 `resultType` 直接写实体类即可，不用写 resultMap；
3. 新增用 `useGeneratedKeys="true" keyProperty="userId"` 回填自增主键。

**ServiceImpl** `service/impl/UserServiceImpl.java` 核心逻辑（全部通过 Mapper 自定义方法访问数据库）：

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class UserServiceImpl implements IUserService {

    private final UserMapper userMapper;
    private final StringRedisTemplate redis;
    private static final String BLACKLIST = "healthai:token:blacklist:";

    @Override
    public Long register(RegisterDto dto) {
        // 1. 查重
        if (userMapper.countByUsername(dto.getUsername()) > 0)
            throw new RuntimeException("用户名已存在");
        // 2. MD5 加密 + 默认角色/状态
        UserEntity u = new UserEntity();
        u.setUsername(dto.getUsername());
        u.setPassword(PasswordUtils.encrypt(dto.getPassword()));
        u.setPhone(dto.getPhone());
        u.setEmail(dto.getEmail());
        u.setRole(0); u.setStatus(1);
        userMapper.insert(u);       // 自增主键回填到 u.userId
        return u.getUserId();
    }

    @Override
    public String login(LoginDto dto) {
        UserEntity u = userMapper.findByUsername(dto.getUsername());
        if (u == null || !PasswordUtils.matches(dto.getPassword(), u.getPassword()))
            throw new RuntimeException("用户名或密码错误");
        if (u.getStatus() == 0) throw new RuntimeException("账号已被禁用");
        return JwtUtils.generateToken(u.getUserId(), u.getUsername());
    }

    @Override
    public void logout(String token) {
        // JWT 无状态，靠 Redis 黑名单实现"主动失效"，TTL = token 剩余有效期
        if (token == null || JwtUtils.isExpired(token)) return;
        long remain = JwtUtils.parse(token).getExpiration().getTime() - System.currentTimeMillis();
        if (remain > 0) redis.opsForValue().set(BLACKLIST + token, "logout", remain, TimeUnit.MILLISECONDS);
    }

    @Override
    public UserEntity getUserInfo(Long userId) {
        UserEntity u = userMapper.findById(userId);
        if (u != null) u.setPassword(null);   // 不返回密码
        return u;
    }

    @Override
    public void updateUserInfo(Long userId, UserEntity entity) {
        entity.setUserId(userId);
        // XML 用 <set> 动态更新，只改 phone/email/avatar，密码/角色/状态传了也不会更新
        userMapper.updateById(entity);
    }
}
```

**ServiceImpl 核心** `service/impl/ChatServiceImpl.java`。整体流程（务必理解每一步的目的）：

```
1. 校验问题非空
2. 限流：Redis 计数器，60 秒内超过 10 次拒绝
3. 生成缓存 key：healthai:answer:{标准化问题}
4. 布隆过滤器预判 → 查 Redis 回答缓存，命中直接返回（<10ms）
5. Redisson 分布式锁 tryLock(3s 等待, 10s 租约)，防同一用户并发重复提问
6. 拿到锁后双重检查缓存（等锁期间可能已被别的请求写入）
7. 确定 sessionId（前端没传就生成 UUID）
8. 从 Redis List 读该会话最近 10 轮上下文
9. 拼提示词（系统角色 + 历史上下文 + 当前问题），调 ChatModel
10. 敏感词过滤
11. 回答写回 Redis 缓存（TTL 30 分钟）
12. 本轮问答写入上下文 List（LPUSH + LTRIM 0 9 + EXPIRE 2h）
13. 异步存 MySQL（@Async）
14. 问题加入布隆过滤器
15. 返回 {answer, isCached, modelName, responseTime}，finally 释放锁
```

关键代码片段：

```java
@Slf4j
@Service
@RequiredArgsConstructor
public class ChatServiceImpl implements IChatService {

    private final ChatHistoryMapper chatHistoryMapper;
    private final RedissonClient redisson;
    private final StringRedisTemplate redis;
    private final ChatModel chatModel;                 // Spring AI 自动注入
    private final SensitiveWordFilter sensitiveFilter;
    private final BloomFilterUtils bloom;

    private static final int CACHE_TTL = 1800;
    private static final int RATE_WINDOW = 60;
    private static final int CONTEXT_SIZE = 10;
    private static final int CONTEXT_TTL = 7200;

    @Override
    public Map<String, Object> askQuestion(Long userId, ChatDto dto) {
        if (dto.getQuestion() == null || dto.getQuestion().isBlank())
            throw new RuntimeException("问题不能为空");

        checkRateLimit(userId);                                   // ② 限流

        String key = "healthai:answer:" + normalize(dto.getQuestion());
        // ④ 布隆预判 + 缓存
        if (bloom.mightContain(dto.getQuestion())) {
            String cached = redis.opsForValue().get(key);
            if (cached != null) return result(cached, true, 0);
        }

        // ⑤ 分布式锁
        RLock lock = redisson.getLock("healthai:submit:lock:" + userId);
        try {
            if (!lock.tryLock(3, 10, TimeUnit.SECONDS))
                throw new RuntimeException("请求处理中，请稍后再试");

            // ⑥ 双重检查
            String cached = redis.opsForValue().get(key);
            if (cached != null) return result(cached, true, 0);

            // ⑦⑧ sessionId + 上下文
            String sessionId = dto.getSessionId() != null && !dto.getSessionId().isBlank()
                    ? dto.getSessionId() : UUID.randomUUID().toString().replace("-", "");
            String context = getContext(sessionId);

            // ⑨ 调 AI
            long t0 = System.currentTimeMillis();
            String answer = callAi(dto.getQuestion(), context);
            long cost = System.currentTimeMillis() - t0;

            // ⑩ 敏感词
            answer = sensitiveFilter.filter(answer);

            // ⑪⑫⑭ 写缓存、上下文、布隆
            redis.opsForValue().set(key, answer, CACHE_TTL, TimeUnit.SECONDS);
            saveContext(sessionId, dto.getQuestion(), answer);
            bloom.add(dto.getQuestion());

            // ⑬ 异步落库
            saveHistoryAsync(userId, dto.getQuestion(), answer, sessionId, cost);

            return result(answer, false, (int) cost);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            throw new RuntimeException("请求被中断");
        } finally {
            if (lock.isHeldByCurrentThread()) lock.unlock();
        }
    }

    // 固定窗口限流
    private void checkRateLimit(Long userId) {
        String k = "healthai:rate:" + userId;
        Long n = redis.opsForValue().increment(k);
        if (n != null && n == 1) redis.expire(k, RATE_WINDOW, TimeUnit.SECONDS);
        if (n != null && n > 10) throw new RuntimeException("提问过于频繁，请稍后再试");
    }

    // 上下文：Redis List，LPUSH 新对话，LTRIM 只留 10 轮
    private String getContext(String sid) {
        List<String> list = redis.opsForList().range("healthai:context:session:" + sid, 0, -1);
        return list == null ? "" : String.join("\n", list);
    }
    private void saveContext(String sid, String q, String a) {
        String k = "healthai:context:session:" + sid;
        redis.opsForList().leftPush(k, "用户：" + q + "\nAI：" + a);
        redis.opsForList().trim(k, 0, CONTEXT_SIZE - 1);
        redis.expire(k, CONTEXT_TTL, TimeUnit.SECONDS);
    }

    // 调 Ollama 大模型
    private String callAi(String question, String context) {
        String system = "你是一位专业的医药健康顾问，擅长解答药品使用、疾病预防、健康养生问题。"
                + "请用通俗易懂的语言回答。回答仅供参考，不能替代专业医生的诊断和治疗建议。";
        StringBuilder prompt = new StringBuilder();
        if (context != null && !context.isBlank())
            prompt.append("【对话历史】\n").append(context).append("\n\n");
        prompt.append("【当前问题】\n").append(question).append("\n\n").append(system);

        var resp = chatModel.call(new Prompt(prompt.toString()));
        String content = resp.getResult().getOutput().getContent();
        if (content == null || content.isBlank()) throw new RuntimeException("AI 未返回内容");
        return content;
    }

    @Async
    public void saveHistoryAsync(Long userId, String q, String a, String sid, long cost) {
        ChatHistoryEntity e = new ChatHistoryEntity();
        e.setUserId(userId); e.setQuestion(q); e.setAnswer(a); e.setSessionId(sid);
        e.setModelName("deepseek-r1"); e.setResponseTime((int) cost);
        e.setIsCached(0); e.setCreateTime(LocalDateTime.now());
        chatHistoryMapper.insert(e);
    }

    private String normalize(String q) { return q.trim().toLowerCase().replaceAll("\\s+", " "); }

    private Map<String, Object> result(String answer, boolean cached, int time) {
        return Map.of("answer", answer, "isCached", cached,
                      "modelName", "deepseek-r1", "responseTime", time);
    }
}
```

```java
public List<CollectInfoDto> getMyCollects(Long userId) {
    // 1. 一次查出该用户所有收藏
    List<UserCollectEntity> collects = collectMapper.selectByUserId(userId);
    if (collects.isEmpty()) return List.of();

    // 2. 收集所有 knowledgeId，一条 IN SQL 批量查询（避免 N+1）
    List<Long> ids = collects.stream().map(UserCollectEntity::getKnowledgeId).toList();
    Map<Long, MedicalKnowledgeEntity> map = knowledgeMapper.selectByIds(ids).stream()
            .collect(Collectors.toMap(MedicalKnowledgeEntity::getKnowledgeId, k -> k));

    // 3. 内存组装 DTO
    List<CollectInfoDto> result = new ArrayList<>();
    for (UserCollectEntity c : collects) {
        MedicalKnowledgeEntity k = map.get(c.getKnowledgeId());
        if (k == null) continue;
        CollectInfoDto dto = new CollectInfoDto();
        dto.setCollectId(c.getCollectId());
        dto.setKnowledgeId(k.getKnowledgeId());
        dto.setTitle(k.getTitle());
        dto.setCategory(k.getCategory());
        dto.setCreateTime(c.getCreateTime().toString());
        result.add(dto);
    }
    return result;
}
```

```js
const request = axios.create({ baseURL: '/api', timeout: 60000 })

// 请求拦截：自动带 token（裸 token，与后端约定一致；登录注册除外）
request.interceptors.request.use(config => {
  const url = config.url
  if (!url.includes('/auth/login') && !url.includes('/auth/register')) {
    const token = localStorage.getItem('token')
    if (token) config.headers.Authorization = token
  }
  return config
})

// 响应拦截：统一解包 Result，401 跳登录
request.interceptors.response.use(
  res => {
    const data = res.data
    if (data.code !== 200) {
      ElMessage.error(data.message || '请求失败')
      if (data.code === 401) {
        localStorage.clear()
        setTimeout(() => location.hash = '#/login', 1000)
      }
      return Promise.reject(data)
    }
    return data           // 业务里直接拿到 {code,message,data}
  },
  err => {
    if (err.response?.status === 401) {
      localStorage.clear()
      location.hash = '#/login'
    } else {
      ElMessage.error(err.response?.data?.message || '网络错误')
    }
    return Promise.reject(err)
  }
)

export default request
```

Chat.vue 发送问答的关键逻辑：

```js
async function send() {
  if (!input.value.trim() || loading.value) return
  if (!currentSession.value) createNewSession()
  const question = input.value.trim()
  messages.value.push({ role: 'user', content: question })
  input.value = ''
  loading.value = true
  messages.value.push({ role: 'ai', loading: true })   // 占位气泡
  try {
    const res = await askQuestionApi({
      question,
      sessionId: currentSession.value
    })
    messages.value.pop()                                // 移除占位
    messages.value.push({
      role: 'ai',
      content: res.data.answer,
      isCached: res.data.isCached,
      responseTime: res.data.responseTime
    })
    await loadSessions()
  } catch (e) {
    messages.value.pop()
  } finally {
    loading.value = false
  }
}
```

## 8.4 MyBatis 常见报错自查

| 报错 | 原因 | 解决 |
|------|------|------|
| Invalid bound statement (not found) | XML 没被找到，或 namespace/id 对不上 | 检查 yml 的 mapper-locations、XML namespace 与接口全限定名、方法 id |
| 列名 Unknown column | SQL 列名与表不一致 | 对照第 3 章建表语句 |
| 分页不生效（返回全部） | startPage 后没有紧跟查询，或漏了依赖 | 确认 pagehelper-spring-boot-starter 已引入，startPage 紧贴查询 |
| 自增主键为 null | insert 没加回填 | XML 的 insert 加 useGeneratedKeys + keyProperty |
| XML 修改不生效 | target 里是旧文件 | Maven → clean，重新启动 |

# 附录 C：重写时建议注意的 10 个问题

1. **DTO 加校验注解**：给 LoginDto/RegisterDto/ChatDto 加 `@NotBlank`，并保留 5.9 的 `MethodArgumentNotValidException` 处理器，否则 `@Valid` 不生效。
2. **配置项真正生效**：把缓存 TTL、限流阈值做成 `@Value("${healthai.chat.cache-ttl:1800}")` 读取，不要硬编码。
3. **布隆过滤器放在缓存查询之前**：`contains()` 返回 false 直接调 AI，省掉一次 Redis 查询。
4. **退出登录要调后端**：前端退出时调 `/api/auth/logout` 写黑名单，不能只清本地存储。
5. **@Async 避免自调用失效**：Spring AOP 同类内部 `this.xxx()` 不走代理，异步落库方法要放到独立 Bean，或注入自身代理。
6. **密码加密升级**：MD5 已不安全，建议换 `BCryptPasswordEncoder`（在 SecurityConfig 声明 PasswordEncoder Bean，登录改用 encoder.matches）。
7. **PageHelper 分页位置**：`PageHelper.startPage()` 必须紧贴目标查询，中间不能有别的 SQL，否则分页到错误语句。
8. **浏览量自增用原子 SQL**：`UPDATE ... SET view_count = view_count + 1`（XML 已给出），避免读-改-写并发丢失。
9. **XML 与接口严格对应**：namespace = 接口全限定名、id = 方法名、`@Param` 名 = `#{}` 名，三者不一致就报 Invalid bound statement。
10. **Markdown 渲染防 XSS**：前端 marked 后用 DOMPurify 消毒再 v-html。

## 学习建议

- 第一遍**严格按阶段顺序**写，每完成一个里程碑就用 Postman 验证，不要一口气全写完再排错。
- 最核心、最值得花时间的是 **6.2 AI 问答**，把「限流 / 缓存 / 布隆 / 分布式锁 / 双重检查 / 多轮上下文」六个机制讲清楚，面试主要问这里。
- 原生 MyBatis 部分重点掌握 **XML 动态 SQL**：`<if>`、`<where>`、`<set>`、`<foreach>`，以及 PageHelper 的 `startPage → 查询 → PageInfo` 三步用法。
- 遇到报错先看控制台 Caused by，常见就是：MySQL/Redis/Ollama 没启动、密码不对、依赖没下载（镜像问题）、XML 没绑定上、JWT 没带对。
